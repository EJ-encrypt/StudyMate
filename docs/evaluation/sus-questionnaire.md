# System Usability Scale (SUS) — StudyMate AI

The standard ten-item SUS instrument (Brooke, 1996), unchanged except that
"system" is named as StudyMate. The wording is deliberately left alone:
altering items breaks comparability with published SUS benchmarks, which
is the main reason for using SUS at all.

Administer **immediately after** the session, before any discussion of the
participant's opinions.

---

## Instructions to the participant

> "Ten statements about the app. For each one, mark how much you agree,
> from 1 (strongly disagree) to 5 (strongly agree). Please answer quickly
> and instinctively rather than deliberating — first reaction is what this
> is designed to capture. Don't leave any blank; if you're unsure, mark 3."

## Scoring

SUS is **not** a percentage, and a score of 68 is not "68% usable". It is a
0–100 scale where 68 is the published average across many systems.

1. **Odd-numbered items (1, 3, 5, 7, 9):** subtract 1 from the response.
   → contribution = response − 1
2. **Even-numbered items (2, 4, 6, 8, 10):** subtract the response from 5.
   → contribution = 5 − response
3. Sum all ten contributions (range 0–40).
4. Multiply the sum by 2.5 → final score, 0–100.

Report the **mean score across participants**, and the range. With five
to eight participants the mean is indicative, not statistically robust —
say so rather than implying precision the sample cannot support.

### Interpreting the result

| Score | Common interpretation |
|---|---|
| Below 51 | Poor — serious usability problems |
| 51–68 | Below average |
| ~68 | Average (the SUS benchmark) |
| 69–80 | Good |
| Above 80 | Excellent |

### Worked example

Responses: 4, 2, 4, 1, 4, 2, 5, 2, 4, 2

- Odd items (1,3,5,7,9): (4−1) + (4−1) + (4−1) + (5−1) + (4−1) = 3+3+3+4+3 = 16
- Even items (2,4,6,8,10): (5−2) + (5−1) + (5−2) + (5−2) + (5−2) = 3+4+3+3+3 = 16
- Sum = 32 → 32 × 2.5 = **80**
